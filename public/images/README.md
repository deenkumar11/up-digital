# Photos go here

Drop your JPG/PNG/WebP files in this folder, then swap the matching
`<ImagePlaceholder .../>` in `src/App.jsx` for a real `<img>` tag, e.g.:

```jsx
<img
  src="/images/team-at-work.jpg"
  alt="UP team at work"
  className="h-full w-full object-cover rounded-2xl"
/>
```
